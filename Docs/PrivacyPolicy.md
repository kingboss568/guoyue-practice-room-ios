# 國樂團練習室 Privacy Policy

Last updated: 2026-05-18

國樂團練習室尊重使用者隱私。本 App 以離線學習為核心，不建立帳號、不投放廣告、不追蹤使用者，也不將學習紀錄上傳到開發者伺服器。

## 資料收集

國樂團練習室不收集可識別個人身分的資料。

App 會在裝置本機儲存以下學習狀態：

- 收藏的樂器
- 已完成課程
- 測驗最佳成績與練習次數

這些資料只儲存在使用者裝置內，用於顯示學習進度。

## 付費購買

國樂團練習室 Pro 使用 Apple StoreKit 處理購買與恢復購買。付款、收據與 Apple ID 相關流程由 Apple 管理，開發者不會取得信用卡或 Apple ID 密碼。

## 網路與第三方服務

本 App 不使用第三方分析 SDK、不使用廣告 SDK、不提供第三方登入，也不追蹤跨 App 或跨網站活動。
