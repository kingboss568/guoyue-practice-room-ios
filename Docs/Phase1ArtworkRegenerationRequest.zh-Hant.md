# 第一階段高風險樂器圖片重做/審核請求

日期：2026-06-15

用途：可交給圖片生成、插畫、設計或國樂專業審核者。這份文件只產生候選圖，不代表可直接進 App。

## 目標

重做或校正 7 件最容易被專業國樂使用者抓包的圖片：

- 革胡
- 嗩吶
- 笙
- 板胡
- 二胡
- 高胡
- 中胡

正式圖必須是單一樂器、乾淨背景、無浮水印、無圖內文字、無 callout、無英文或中文說明標籤。即使是教學用途，也不能把標註文字留在 App 圖片中；審核資料可以另外寫在 JSON 或文件裡。

目前 `Design/Review/ArtworkCandidates/candidate_<instrument_id>.png` 已重生成無圖內標註候選圖；`candidate_<instrument_id>_annotated_reference.png` 只供形制討論參考，不得送審或匯入 App。

## 必須避免

- 革胡不可畫成二胡、中胡或普通西洋大提琴。
- 嗩吶不可畫成小號、薩克斯風、單簧管或西式雙簧管。
- 笙不可畫成排簫、管風琴、風笛或隨機竹管束。
- 板胡不可只是一般二胡換標籤，需看出板面或椰殼/木質小共鳴體。
- 二胡、高胡、中胡必須能靠琴筒大小、比例和音域角色區分；不能只靠文字。
- 不可使用幻想、科幻、金屬裝甲、舞台概念道具或混合不存在的構造。
- 不可照抄網路參考照片；只參考形制與比例。

## 逐項重做重點

### 革胡

大型低音拉弦樂器，接近 cello-like 垂直尺度，但要保留中國樂團低音拉弦樂器特徵。需要大型共鳴體、長頸、弦、橋與低位支撐或 endpin。縮圖時也要看得出比中胡、二胡大很多。

### 嗩吶

短錐形木質管身，前方指孔，小雙簧與芯子/接管，底部有可拆式金屬喇叭口。整體是 shawm，不是銅管樂器；不可有 trumpet tubing、saxophone 曲線或 clarinet 長圓柱比例。

### 笙

多根高度不同的直立管，插入斗子/風箱，帶清楚吹嘴。管束是核心輪廓，斗子和吹嘴必須在小卡片尺寸仍可見。不可像排簫或沒有風箱的竹管束。

### 板胡

胡琴族直立拉弦形制，兩弦與弓毛在弦間。小共鳴體需呈現板面或椰殼/木質特徵，不能是標準二胡的蟒皮琴筒。整體要比中胡小、比二胡更尖亮。

### 二胡

標準胡琴族中間參考尺寸。需要小型蟒皮琴筒、兩弦、兩個軸、弓毛在兩弦之間。不要畫成板胡木板面，也不要放大成中胡或革胡。

### 高胡

比二胡更小、更高音域、更輕巧。可暗示粵樂高胡的緊湊比例，但不要加演奏者遮住樂器。不可和二胡同尺寸。

### 中胡

比二胡更大、更低音域，琴筒和琴桿更厚實，但不可大到革胡尺度。必須和二胡、高胡保持相對比例差異。

## 審核與匯入

候選圖先放在：

```text
Design/Review/ArtworkCandidates/
```

候選圖 manifest 必須標出是否無圖內標註：

```json
"annotation_status": "no_internal_text_labels"
```

目前帶 callout 或文字的候選圖只能標為：

```json
"annotation_status": "annotated_morphology_reference"
```

只有專業審核通過、approval JSON 確認 `no_visible_internal_text_labels`，並且 `import_approved_artwork.py --approve` 完成後，才可替換正式 App asset。
