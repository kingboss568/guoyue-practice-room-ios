# 競品差異與素材重製計畫

日期：2026-06-15

## 競品觀察

目前搜尋到的相近 App 大多不是「整個國樂團專業練習室」，而是單一樂器學習、調音器、曲譜或泛中國音樂播放器。

- 《笛子教練》主打同步學笛子曲譜、手機演奏、影片教學與老師交流，強項是單一樂器學習流程。
- 《二胡音階練習》與相關二胡工具偏向音階、音準、調音等練習工具。
- 《民樂調音器》類產品強調真實音色採樣資料與民族樂器定弦識別，這點直接打中專業者信任。
- 泛中國古典音樂播放器提供大量曲目，但通常不是可稽核的專業練習工具，也不保證曲目/錄音授權適合包進付費 App。

## 本 App 目前差異

優勢：

- 以國樂團四大聲部做整體地圖，不只單一樂器。
- 已有 23 件樂器、名曲名家、課程、測驗、進度與 StoreKit 架構。
- SwiftUI、Fastlane、隱私頁、支援頁與截圖流程已具備上架基礎。

弱點：

- 目標若改成專業演奏者，目前內容深度、音色可信度與圖片準確度不足。
- 現有音檔是生成式短樣本，不應作為專業聽辨賣點。
- 樂器圖雖比抽象圖好，但仍有形制混淆風險。
- Pro 價值目前偏「解鎖更多內容」，缺少演奏者願意付費的硬工具，例如調音/節拍/分部練習/曲目備演清單。

## 改版定位

建議將 App 從「初學國樂圖鑑」改成：

「國樂團演奏者的練團前複習與聽辨工具」

上架文案應強調：

- 聲部分工與舞台編制。
- 實器音色辨識與技法聽感。
- 經典曲目背景與排練提示。
- 教師/團員可快速備課、備演、複習。

## 音源路線

優先順序：

1. 自行錄製或委託演奏者錄 23 件單音/短句，簽授權同意可商業 App 使用。
2. 使用付費 sample library 或平台音源，但需確認授權允許把 sample 以 App bundle 形式散布。
3. 使用 CC0 / CC-BY 樣本時，逐筆保留來源、作者、授權截圖與 attribution。
4. Suno 或其他生成音樂 API 僅可用於背景音景或 demo 草稿，不作為專業樂器音色樣本，除非通過真人演奏者盲聽。

## 曲目著作權原則

台灣智慧財產局資料顯示，「音樂著作」通常為著作人生存期間及死亡後 50 年；「錄音著作」為公開發表後 50 年。即使曲本身已成公共財，現代錄音仍可能受錄音著作權保護。因此 App 內若要包入名曲音檔，需同時確認曲與錄音兩層權利。

初步判斷：

- 古曲或傳統曲牌可列為優先研究對象，但仍要避免使用受保護的現代編曲/錄音。
- 《二泉映月》曲作者華彥鈞 1950 年逝世，曲在台灣可能已過音樂著作保護期，但錄音仍需逐筆授權。
- 《賽馬》《姑蘇行》《瑤族舞曲》等近現代作品不應直接包入音檔，除非取得授權。
