# 國樂團練習室 Support

國樂團練習室是一款離線國樂教育 App，提供國樂團聲部、樂器圖鑑、名曲導聆、課程、測驗與 Pro 進階練習。

## 常見問題

### App 是否需要登入？

不需要。國樂團練習室不要求註冊帳號，也不提供第三方登入。

### App 是否需要網路？

主要內容、已核准樂器插圖與已核准聲音樣本都可離線使用。Pro 購買與恢復購買會透過 Apple StoreKit 連線至 App Store。

### Pro 解鎖後包含什麼？

Pro 解鎖 23 種樂器各 50 題、230 題基礎知識與目前全部已核准實器聽辨題。正式版不會以 AI、電子波形或相近樂器冒充缺少的國樂實器聲音。

### 如何恢復購買？

請前往 App 內的「Pro」頁籤，點選「恢復購買」。
